# ZXDrawer: Emulador de Sprite integrado, Pegado Flotante y Relleno · v1.0.34

---

## [ES] Español

### Resumen
La versión **1.0.34** introduce un emulador de pantalla ZX Spectrum integrado para probar animaciones y sprites (incluyendo físicas y vista isométrica), incorpora una nueva herramienta de relleno (cubo de pintura) y permite un pegado flotante con precisión de píxel.

### Novedades y Mejoras

1. **Nuevo Sistema de Emulación Integrado**
   - **Emulador de Pantalla ZX Spectrum:** Hemos añadido un botón de "Emular" en el visor de animaciones. Ahora puedes probar tus sprites directamente en una pantalla simulada de 256x192, moviéndolos con los controles clásicos: **O, P, Q, A**.
   - **Físicas y Modos de Juego:** El emulador soporta diferentes modos:
     - **Cenital (Top-Down):** Ideal para juegos de rol o exploración vista desde arriba.
     - **Plataformas (Lateral):** Incluye físicas básicas con gravedad y saltos.
     - **Isométrico:** ¡Nuevo modo para probar movimientos diagonales al estilo de los clásicos como *Knight Lore*!
   - **Asignación de Frames de Acción:** Mapea visualmente qué frame corresponde a cada acción (arriba, abajo, salto, reposo, etc.).
   - **Nueva Interfaz del Emulador:** Layout a dos columnas para aprovechar mejor el espacio.

2. **Mejoras en Animaciones**
   - **Previsualización de Animaciones Verticales:** Ahora puedes previsualizar animaciones dispuestas verticalmente, definiendo el "Alto del Frame" en lugar de solo el ancho.

## [EN] English

### Summary
Version **1.0.34** introduces a built-in ZX Spectrum screen emulator to test animations and sprites (including physics and isometric views), a new flood fill tool, and allows pixel-perfect floating paste adjustments.

### Features and Improvements

1. **New Built-in Emulation System**
   - **ZX Spectrum Screen Emulator:** We've added an "Emulate" button in the animation viewer. Test your sprites directly on a simulated 256x192 screen using classic controls: **O, P, Q, A**.
   - **Physics and Game Modes:** The emulator supports different modes:
     - **Top-Down:** Perfect for RPGs or exploration.
     - **Platformer:** Includes basic physics with gravity and jumping.
     - **Isometric:** Test diagonal movements in the style of classic games like *Knight Lore*!
   - **Action Frame Mapping:** Visually map which frame corresponds to each action (up, down, jump, idle, etc.).
   - **New Emulator UI:** Two-column layout to make better use of screen space.

2. **Animation Improvements**
   - **Vertical Animation Previews:** You can now preview vertically laid out animations by defining the "Frame Height" instead of just the width.

3. **New Drawing and Editing Tools**
   - **Flood Fill Tool:** Fill contiguous pixel areas with ink or paper (hotkey `F`). If a selection is active, it applies attributes (ink, paper, brightness, and flash) to the whole area without modifying pixels.
   - **Floating Pixel-Perfect Paste:** When pasting, adjust the selection pixel by pixel using the mouse or keyboard arrows before committing. Press `Enter` to confirm or `Escape` to cancel.

## [PT] Português

### Resumo
A versão **1.0.34** introduz um emulador integrado de tela ZX Spectrum para testar animações e sprites (incluindo físicas e vista isométrica), adiciona uma nova ferramenta de preenchimento (balde de tinta) e permite colar seleções com precisão pixel-perfect de forma flutuante.

### Novidades e Melhorias

1. **Novo Sistema de Emulação Integrado**
   - **Emulador de Tela ZX Spectrum:** Adicionamos um botão "Emular" no visualizador de animações. Teste seus sprites diretamente em uma tela simulada de 256x192 com os controles clássicos: **O, P, Q, A**.
   - **Físicas e Modos de Jogo:** O emulador suporta diferentes modos:
     - **Top-Down:** Ideal para RPGs e exploração.
     - **Plataformas:** Inclui físicas básicas com gravidade e saltos.
     - **Isométrico:** Teste movimentos diagonais ao estilo de jogos clássicos como *Knight Lore*!
   - **Mapeamento de Frames de Ação:** Mapeie visualmente qual frame corresponde a cada ação (cima, baixo, pular, parado, etc.).
   - **Nova Interface do Emulador:** Layout em duas colunas para melhor aproveitamento do espaço.

2. **Melhorias em Animações**
   - **Pré-visualização de Animações Verticais:** Agora é possível pré-visualizar animações organizadas verticalmente, definindo a "Altura do Frame" em vez da largura.

3. **Novas Ferramentas de Desenho e Edição**
   - **Nova Ferramenta de Preenchimento:** Preencha áreas de pixels contíguas com tinta ou papel (tecla `F`). Com uma seleção ativa, aplica os atributos (tinta, papel, brilho e piscar) a toda a área sem alterar os pixels.
   - **Colagem Flutuante "Pixel-Perfect":** Ao colar, ajuste a seleção pixel por pixel usando o mouse ou setas do teclado antes de fixar. Pressione `Enter` para confirmar ou `Escape` para cancelar.
